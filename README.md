# 🚌 RedBus Web Scraping + Streamlit App

This project scrapes real-time bus data from [RedBus.in](https://www.redbus.in/) including:
- Bus operator
- Boarding & Dropping points
- Departure & Arrival times
- Seat availability
- Ticket price
